Tu CRM de WhatsApp, sin 41 pasos manuales.

Un instalador guiado para crear una bandeja compartida, embudo de ventas, campañas, automatizaciones y asistente de IA en tu propio servidor.

Ver instalación en GitHub Conocer wacrm
01

Prepará el equipo

Instalá Node.js 20+, Git y Docker en el servidor que alojará el CRM.

02

Conectá tus cuentas

Ingresá las credenciales de Supabase y de la API oficial de Meta.

03

Ejecutá el instalador

El asistente crea la base de datos, configura el webhook y comprueba la instalación.

git clone https://github.com/mdsajid-ui/crm-whatsapp-instalador-Sajid.git && cd crm-whatsapp-instalador-Sajid && npm run instalar
El instalador se ejecuta localmente o en un VPS. No ingreses credenciales de Meta o Supabase en este sitio.
